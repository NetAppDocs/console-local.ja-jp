= NetApp Console ローカル展開の受信ポート
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console のローカル展開用 OVA は、独自の内部ファイアウォールを管理します。お客様の環境で VM に対して外部ファイアウォールポリシーが適用されている場合は、管理ホストから以下の受信ポートにアクセスできることを確認してください。

[cols="10,10,80"]
|===
| ポート | Protocol | 目的 


| 22 | TCP | SSHを使用してリモートメンテナンスおよび診断シェルにアクセス 


| 123 | UDP | 時刻同期のためのNTP 


| 2379 | TCP | RKE2コントロールプレーンのetcdクライアントトラフィック用etcdクライアントAPI 


| 2380 | TCP | etcdメンバー間レプリケーション用のetcdピアポート 


| 6443 | TCP | kubectlおよびRKE2 APIへのアクセス用Kubernetes APIサーバー 


| 8472 | UDP | RKE2ノード間のポッド間トラフィックのためのCanal/Flannel VXLANオーバーレイ 


| 9091 | TCP | CNIの健全性と指標に関するCalico Felixの指標エンドポイント 


| 9100 | TCP | ホストメトリクスのスクレイピングのためのPrometheus node_exporter 


| 9345 | TCP | RKE2スーパーバイザーおよびサーバー登録エンドポイント 


| 10250 | TCP | kubelet の metrics-server および kube-apiserver 用 Kubelet API 
|===
