= NetApp ConsoleのローカルデプロイにおけるオンプレミスConsoleエージェント用のポート
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console のローカル展開では、コンソールエージェントはオンプレミスの Linux ホストに手動でインストールされた場合、_inbound_ ポートを使用します。計画立案の際には、これらのポートを参考にしてください。

これらの受信ルールは、すべての NetApp Console 展開モードに適用されます。

[cols="10,10,80"]
|===
| Protocol | ポート | 目的 


| HTTP | 80  a| 
* クライアントのWebブラウザからローカルユーザーインターフェースへのHTTPアクセスを提供します。
* Cloud Volumes ONTAP アップグレードプロセス中に使用されます




| HTTPS | 443 | クライアントのウェブブラウザからローカルユーザーインターフェースへのHTTPSアクセスを提供します。 
|===
