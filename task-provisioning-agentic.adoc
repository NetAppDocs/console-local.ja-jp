= AI支援（エージェント）ワークフローを使用して NetApp Console ローカル展開でストレージをプロビジョニングする
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console のローカル展開では、対話形式でストレージをリクエストし、提案されたプランを確認して変更を承認する場合に、AI支援（エージェント）プロビジョニングを使用します。このアプローチは、ストレージクラスと RBAC に合わせたプロビジョニングを維持しながら、UI 操作を減らしてリクエストを高速化したい場合に役立ちます。


NOTE: LLMをコンソールアシスタントに接続してAI機能を有効にする方法に関するこのドキュメントは、技術プレビューとして提供されています。このプレビュー版では、NetApp は一般提供開始前に、提供内容、コンテンツ、およびスケジュールを変更する権利を留保します。

.必要なアクセスロール
スーパー管理者、組織管理者、フォルダまたはフリート管理者、またはストレージ管理者。AIによるアクションは、UIベースのアクションと同じロールベースのアクセス制限を受けます。link:reference-iam-predefined-roles.html["アクセスロールについて"]。

エージェントプロビジョニングには、LLM統合が構成され、NetApp Console のローカル展開環境で利用可能になっている必要があります。



[[before-you-begin]]
== 開始する前に

* LLM統合が構成され、NetApp Console のローカル展開で有効になっていることを確認してください。
* ターゲットフリートに検出済みのストレージシステムが含まれていることを確認してください。
* ストレージクラスが設定され、フリートに関連付けられていることを確認してください。そうすることで、アシスタントがクラスに合わせたプランを提案できるようになります。


.手順（後日再検討予定）
. NetApp Console アシスタントを開きます。
. 必要な内容を平易な言葉で説明してください（例：プロトコル、サイズ、環境、パフォーマンスの目的、該当する場合は対象フリートなど）。
. 提案された計画をレビューします。レビュー項目には以下が含まれます：選択された機器群と対象システムの配置（該当する場合）、選択または推奨されるストレージクラス、適用される主要な設定（容量動作、保護スケジュール、セキュリティ要件、および表示されている場合はQoS関連の意図）
. 計画を確認または調整します。プランで予期しないクラスや配置が選択された場合は、希望するクラス、フリート、または制約を指定してプランを再生成してください。
. ワークロードをプロビジョニングするための実行を承認します。
. ストレージインベントリで作成されたリソースを確認し、継続的なドリフト監視のために、意図したストレージクラスに関連付けられていることを確認してください。
