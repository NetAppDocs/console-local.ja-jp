= NetApp Console のローカル展開で NetApp Console アシスタントを使用する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console のローカル展開で NetApp Console アシスタントを使用して、ストレージを管理したり、自然言語で回答を取得したりできます。必要なことを平易な言葉で説明すると、NetApp Console のローカル展開がストレージポリシーとロールベースアクセスの範囲内でそれを実行します。


NOTE: LLMをコンソールアシスタントに接続してAI機能を有効にする方法に関するこのドキュメントは、技術プレビューとして提供されています。このプレビュー版では、NetApp は一般提供開始前に、提供内容、コンテンツ、およびスケジュールを変更する権利を留保します。

アシスタントの操作は、割り当てられたロールベースのアクセス権によって制限されます。link:reference-iam-predefined-roles.html["アクセスロールについて"]。



[[see-what-you-can-do-with-the-console-assistant]]
== コンソールアシスタントでできることを確認する

対話型のインターフェースを通じてストレージの状態とサポートされている操作を特定することで、ガイダンスや介入が必要なタイミングを判断できます。質問をしたり、タスクを説明したりすると、回答、分析結果、または提案されたアクションが返されます。このアシスタントは以下の機能を提供します：

* *ストレージのプロビジョニング* ワークロードを平易な言葉で説明します。アシスタントはストレージクラスと配置場所を推奨し、詳細を確認後、ボリュームまたはLUNを作成します。例えば、特定の容量を持つCIFSボリュームを作成するように指示します。アシスタントは、クラスターとストレージ仮想マシン（SVM）を識別し、必要なパラメーターを入力し、ストレージをプロビジョニングします。
* *メトリクスの分析* 許可された範囲内のリソースについて、サポートされている容量、パフォーマンス、ストレージのメトリクスについてお問い合わせください。アシスタントは、利用可能なフリート状態に基づいて読み取り専用の分析結果を返します。
* *検索してガイダンスを取得* ストレージ環境に関する質問をしたり、コンソールのローカル展開機能を見つけたり、NetApp ドキュメントおよび現在のフリート状態からコンテキストに応じた回答を取得したりできます。
* *アラートの調査* アシスタントにアクティブなアラートを調査するように依頼します。問題点を分析し、解決策を提案するか、お客様の確認を得た上で修復措置を実行します。
* *ONTAP システムの管理* サポートされている ONTAP 管理操作を自然言語でリクエストします。アシスタントは、不足しているシステムまたは SVM コンテキストを特定し、提案された操作を提示し、書き込み操作の前に確認を求めます。


アシスタントは、コンソールのローカル展開で管理者が設定したLLMエンドポイントにのみリクエストを送信します。ストレージ変更アクションを実行する前に確認を要求し、すべてのアクションはお客様のアカウントに割り当てられたロールベースのアクセス制御に従います。



[[confirm-that-you-can-use-the-console-assistant]]
== コンソールアシスタントが使用できることを確認してください。

* 組織管理者またはスーパー管理者は、大規模言語モデル（LLM）をコンソールのローカル展開に接続することにより、コンソールアシスタントを有効にする必要があります。ダッシュボードに「コンソールアシスタント」ボタンが表示されない場合は、管理者に有効化を依頼してください。link:task-llm-connect.html["LLMを接続してNetApp Consoleアシスタントを有効にする方法をご確認ください"]。
* アシスタントに実行させたい操作に必要なロールベースのアクセス制御が設定されていることを確認してください。




[[ask-the-console-assistant-a-question-or-request-an-action]]
== コンソールアシスタントに質問するか、アクションをリクエストしてください。

サポート対象のストレージに関する作業は、対話形式で依頼することで、提案された変更がインフラストラクチャに影響を与える前に評価できます。

.手順
. NetApp Console のローカル展開ダッシュボードで、「コンソールアシスタント」ボタンを選択します。
. アクセスモードを選択してください：
+
** 変更を加えることなく質問やガイダンスを受けるには、*閲覧専用* を選択してください。
** アシスタントがストレージインフラストラクチャ上で操作できるようにするには、「読み取り/書き込み」を選択します。


. 質問やタスクの内容を説明するプロンプトを入力し、*送信*を選択してください。
+
例： `Create a 10GiB volume for home directories named home, and share it with Everyone set to FULL_CONTROL.`

. アシスタントの回答を確認してください。
+
** 質問に対して、アシスタントはお客様が対応できる回答を返します。
** 操作を行う際、アシスタントは推奨される操作を表示し、権限レベルなどの不足している詳細情報を尋ね、その後、実行前に確認を求めます。


. 操作を確認してください。ボリューム作成などの非同期操作の場合、アシスタントはリクエストを完了するためのジョブを作成します。
. 依頼内容を確認するには、アシスタントにお問い合わせください。例えば、 `Let me know when the job completes`と入力すると、アシスタントは現在のステータスを返します。




[[use-the-assistant-for-metrics-and-analytics]]
== 指標と分析にはアシスタントを使用します

理解したいリソース、範囲、指標、期間を特定する読み取り専用の質問をしてください。アシスタントはサポートされている指標の分析結果を返し、お客様のストレージは変更しません。



[[use-the-assistant-for-ontap-management]]
== アシスタントを使用した ONTAP 管理

サポートされているONTAP操作を、審査済みのアシスタント提案を通じて管理することで、インフラの変更が計画的かつ許可制で行われるようにします。

link:reference-console-assistant-operations.html["サポートされているコンソールアシスタント操作について"]。
