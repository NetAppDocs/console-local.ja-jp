= NetApp Consoleのローカル デプロイでサポートされているConsoleアシスタントの操作
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
コンソールアシスタントは、自然言語による質問と、選択されたストレージ操作をサポートします。利用可能な操作は、リリース、設定されているLLMエンドポイント、およびお客様に割り当てられた権限によって異なります。


NOTE: LLMをコンソールアシスタントに接続してAI機能を有効にする方法に関するこのドキュメントは、技術プレビューとして提供されています。このプレビュー版では、NetApp は一般提供開始前に、提供内容、コンテンツ、およびスケジュールを変更する権利を留保します。

インフラストラクチャの変更を伴わない質問や分析には、コンソールアシスタントを *読み取り専用* モードで使用してください。ストレージまたは ONTAP システムを変更する可能性のあるサポートされている操作には、*読み取り/書き込み* モードを使用します。アシスタントは提案された変更内容を表示し、書き込み操作を実行する前に確認を求めます。



[[conversational-guidance-and-search]]
== 会話型ガイダンスと検索

NetApp Console のローカル展開、ストレージ環境、またはサポートされている ONTAP 管理ワークフローについて質問してください。アシスタントは、設定済みの LLM エンドポイントと利用可能なドキュメントおよびフリートコンテキストを組み合わせて、回答を返すか、追加のコンテキストを要求します。



[[metrics-and-analytics]]
== 指標と分析

許可された範囲内のリソースについて、サポートされているストレージ容量、パフォーマンス、その他の指標に関する読み取り専用の質問をしてください。質問に関連する場合は、リソース、指標、および期間を含めてください。

アシスタントは分析結果を返し、*読み取り専用*モードではストレージを変更しません。



[[storage-provisioning]]
== ストレージのプロビジョニング

ワークロードとそのストレージ要件を自然言語で記述してください。アシスタントは、ストレージクラスと配置場所を推奨し、不足している詳細情報を特定し、レビュー用のプロビジョニング プランを提示できます。

プランを承認すると、アシスタントは、お客様のロールベースの権限とストレージクラスポリシーに基づいて、サポートされているボリュームまたはLUN操作をプロビジョニングします。link:task-provisioning-agentic.html["AIを活用したワークフローでストレージ プロビジョニングを行う方法をご確認ください。"]。



[[alert-investigation-and-remediation]]
== アラートの調査と修復

アシスタントに、サポートされているアクティブなアラートの調査を依頼してください。アラートを分析し、是正措置を提案する場合があります。サポートされている修復処理がストレージを変更する場合、アシスタントは確認のためにその操作を提示し、実行前に確認を求めます。



[[ontap-management]]
== ONTAPの管理

登録済みの ONTAP システムに対して、サポートされている管理操作を自然言語でリクエストしてください。対象となるクラスター、SVM、またはリソースがわかっている場合は、それを特定してください。そうすることで、アシスタントが適切なコンテキストを使用できます。

アシスタントは、読み取り専用リクエストと書き込み操作を区別します。書き込み操作を確定する前に、対象と提案された変更内容を確認してください。利用可能な操作セットは、Console のローカル展開リリースと、お客様のアカウントに割り当てられている権限によって異なります。



[[permissions-and-scope]]
== 権限と範囲

アシスタントは、サインインしているユーザーの権限とリソーススコープを使用します。

* お客様のロールによって、表示または変更できるリソースと操作が決まります。
* 組織、フォルダ、およびフリートの範囲によって、アシスタントが利用できるシステムとワークロードが制限されます。
* ストレージクラスポリシーは、AI支援によるプロビジョニングを制約します。
* アシスタントは、コンソールのローカル展開アクセス制御をバイパスしません。


link:reference-iam-predefined-roles.html["NetApp Console ローカル展開アクセスロールについて"]。



[[asynchronous-operations]]
== 非同期操作

サポートされている書き込み操作の中には、すぐに完了しないものがあります。これらの操作では、アシスタントがジョブを作成します。完了状況を監視するには、アシスタントにリクエストのステータスを確認してください。
