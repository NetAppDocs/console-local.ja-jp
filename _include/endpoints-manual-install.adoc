イメージを取得するには、インストーラーはこれら2つのエンドポイントセットのいずれかにアクセスできる必要があります。^1^ オプション 1 に記載されているエンドポイントは、より安全であるため推奨されます。オプション1に記載されているエンドポイントは許可し、オプション2に記載されているエンドポイントは許可しないようにファイアウォールを設定することをお勧めします。これらのエンドポイントについて、以下の点にご注意ください。

* オプション1に記載されているエンドポイントは、Console エージェントの3.9.47リリース以降でサポートされています。Console エージェントの以前のリリースとの下位互換性はありません。
* コンソールエージェントは、まずオプション2に記載されているエンドポイントに接続します。これらのエンドポイントにアクセスできない場合、コンソールエージェントはオプション1に記載されているエンドポイントに自動的に接続します。
* オプション 1 のエンドポイントは、Console エージェントを NetApp Backup and Recovery または NetApp Ransomware Resilience と併用する場合はサポートされません。この場合、オプション 1 に記載されているエンドポイントを禁止し、オプション 2 に記載されているエンドポイントを許可することができます。
