「レビュー」ページで「エージェント構成の検証」チェックボックスを選択した場合、コンソールは作成後にコンソールエージェントの構成を検証します。コンソールがエージェントのデプロイに失敗した場合、トラブルシューティングに役立つダウンロード可能なレポートが提供されます。


NOTE: コンソールがエージェントのデプロイに成功した場合、レポートは生成されず、デプロイが成功したことを確認するダイアログが表示されます。

.手順
. 「エージェントの展開に失敗しました」ダイアログボックスで、「レポートをダウンロード」を選択すると、検証レポートを含む PDF ファイルをダウンロードできます。
. または、*最初からやり直す*を選択して*エージェントのデプロイ*ウィザードに戻り、もう一度試すこともできます。
+
エージェントのデプロイを再度試みる場合は、プロセス全体を最初からやり直す必要があります。



コンソールエージェントホストからレポートとログにアクセスする
