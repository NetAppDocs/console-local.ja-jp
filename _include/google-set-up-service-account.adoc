ロールを作成し、コンソールエージェントの VMインスタンスに使用するサービスアカウントに適用します。

.手順
. Google Cloud でカスタムロールを作成する：
+
.. link:reference-permissions-gcp.html["Google Cloud のコンソールエージェントポリシー"]で定義された権限を含む YAML ファイルを作成します。
.. Google Cloud からクラウドシェルを有効化します。
.. コンソールエージェントに必要な権限を含むYAMLファイルをアップロードしてください。
.. カスタムロールを作成するには、 `gcloud iam roles create`コマンドを使用します。
+
次の例では、プロジェクトレベルで「connector」という名前のロールを作成します。

+
[source, gcloud]
----
gcloud iam roles create connector --project=myproject --file=connector.yaml
----
+
https://cloud.google.com/iam/docs/creating-custom-roles#iam-custom-roles-create-gcloud["Google Cloud ドキュメント：カスタムロールの作成と管理"^]



. Google Cloudでサービスアカウントを作成します：
+
.. IAM & Admin サービスから、「サービス アカウント」>「サービス アカウントの作成」を選択します。
.. サービスアカウントの詳細を入力し、*作成して続行*を選択してください。
.. 先ほど作成したロールを選択します。
.. 役割を作成するための残りの手順を完了してください。
+
https://cloud.google.com/iam/docs/creating-managing-service-accounts#creating_a_service_account["Google Cloud ドキュメント：サービスアカウントの作成"^]





.結果
これで、コンソールエージェントのVMインスタンスに割り当てることができるサービスアカウントが作成されました。
