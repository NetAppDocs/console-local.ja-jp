Azure ポータルにアクセスし、1 つ以上のサブスクリプションに対して、コンソール エージェント仮想マシンに Azure カスタム ロールを割り当てます。

.手順
. Azure ポータルから「サブスクリプション」サービスを開き、お客様のサブスクリプションを選択します。
+
役割を割り当てる際は、*Subscriptions* サービスから行うことが重要です。これにより、サブスクリプションレベルでの役割割り当てのスコープが規定されます。_scope_ は、アクセスが適用されるリソースのセットを定義します。別のレベル（たとえば仮想マシンレベル）でスコープを指定すると、NetApp Console 内からアクションを完了する能力に影響が生じます。

+
https://learn.microsoft.com/en-us/azure/role-based-access-control/scope-overview["Microsoft Azure ドキュメント：Azure RBAC の適用範囲を理解する"^]

. 「アクセス制御 (IAM)」>「追加」>「ロール割り当ての追加」を選択します。
. 「Role」タブで、「Console Operator」ロールを選択し、「Next」を選択します。
+

NOTE: Console Operator は、ポリシーで指定されているデフォルト名です。ロールに別の名前を選択した場合は、その名前を選択してください。

. 「メンバー」タブで、以下の手順を実行してください：
+
.. *管理対象ID*へのアクセス権を割り当てます。
.. 「Select members」を選択し、コンソールエージェント仮想マシンが作成されたサブスクリプションを選択します。「Managed identity」の下にある「Virtual machine」を選択し、コンソールエージェント仮想マシンを選択します。
.. 「選択」を選択します。
.. 「次へ」を選択します。
.. 「Review + assign」を選択してください。
.. 追加の Azure サブスクリプションでリソースを管理する場合は、そのサブスクリプションに切り替えてから、これらの手順を繰り返してください。
